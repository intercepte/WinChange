WinChange
WinChange is a lightweight, windows 11 x64 desktop utility designed for power management, system monitoring, and quick access to Windows tools. It runs entirely in the system tray/desktop with a highly customizable, dark-themed UI.
✨ Main Features

    Power Plan Management: Instantly switch between Eco, Balanced, and Performance power schemes.
    System Actions with Countdown: Sleep, Shutdown, Restart, and Hibernate with a customizable delay (allowing you to cancel). Includes "Reinforced Methods" to force-close apps if standard actions fail.
    Smart Inactivity Monitor: Automatically trigger system actions after a set idle time. It tracks 6 real-time sensors to reset the timer: Mouse, Keyboard, Audio, Network, CPU, and GPU.
    Symlink / Redirection Manager: A built-in GUI to easily create, manage, and verify folder/file symbolic links and junctions (useful for moving heavy folders to another drive).
    Custom Tools & Shortcuts: Create, edit, and launch your own custom commands or shortcuts directly from the home screen (with Admin rights support).
    System Utilities: Quick launch for built-in Windows tools (Task Manager, CMD, Registry Editor, Disk Cleanup, etc.) and a dedicated "Restart Explorer" button that safely reopens your previously opened folders.
    Audio & Clock: Master volume slider, mute toggle, and real-time clock directly on the main dashboard.
    Highly Customizable UI: Adjust transparency, change fonts/sizes, and toggle the visibility of almost every UI element.
    Multi-language Support: Easily translate the interface using external .lang.txt files.
    Quick Notes: Built-in notepad to save quick text notes locally.
