# 🌐 English
WinChange

[🇫🇷 Lire en Français](README.FR.md) • [📥 Download Latest Release](https://github.com/VOTRE_PSEUDO/WinChange/releases/latest)

**WinChange** is a lightweight windows 11 x64 desktop utility designed for power management, system monitoring, and quick access to Windows tools. It runs entirely on the desktop with a highly customizable, dark-themed UI.

## ✨ Main Features

*   **Power Plan Management:** Instantly switch between Eco, Balanced, and Performance schemes.
*   **System Actions with Countdown:** Sleep, Shutdown, Restart, and Hibernate with a customizable delay. Includes "Reinforced Methods" to force-close apps if standard actions fail.
*   **Smart Inactivity Monitor:** Automatically trigger actions after a set idle time. Tracks **6 real-time sensors** to reset the timer: Mouse, Keyboard, Audio, Network, CPU, and GPU.
*   **Symlink / Redirection Manager:** Built-in GUI to easily create, manage, and verify folder/file symbolic links and junctions.
*   **Custom Tools & Shortcuts:** Create, edit, and launch your own custom commands directly from the home screen (with Admin rights support).
*   **System Utilities:** Quick launch for Windows tools (Task Manager, CMD, Registry, etc.) and a "Restart Explorer" button that safely reopens your previously opened folders.
*   **Audio & Clock:** Master volume slider, mute toggle, and real-time clock on the main dashboard.
*   **Highly Customizable UI:** Adjust transparency, change fonts/sizes, and toggle the visibility of almost every UI element.
*   **Multi-language Support:** Easily translate the interface using external `.lang.txt` files.
*   **Quick Notes:** Built-in notepad to save quick text notes locally.
